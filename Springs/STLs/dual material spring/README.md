The STL and FreeCAD design file for the dual material spring can be found here.

This is a remix of the Innerbushman alternate spring/magnet plate design. Print the spring in TPU first
then the magnet plate/ spring holder second pausing the print befor it closes the top. This is two layers before
the print finishes if printed with a 0.2mm layer height. You can then insert the TPU spring, checking that the 
orientation is correct and then continue the print.
